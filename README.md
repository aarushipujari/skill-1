
# My Full Stack Project

## Description
A responsive webpage created using semantic HTML5 and external CSS.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- Media Queries
- Git and Git branches

## Features
- Semantic HTML structure
- External stylesheet
- Flexible layouts using Flexbox
- Responsive design for desktop, tablet, and mobile
- Hover effects and smooth scrolling

## How to Run
1. Download or clone the repository.
2. Open index.html in a web browser.

## Git Workflow
- Initialized the Git repository.
- Committed the initial HTML page.
- Added responsive CSS styling.
- Created a feature branch.
- Committed a feature change.
- Merged the feature branch into main.
